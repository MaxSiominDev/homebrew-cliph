# homebrew-cliph

Homebrew tap for [ClipboardHistory](https://github.com/MaxSiominDev/MacOSClipboardHistory), a macOS menu bar clipboard history manager
## Install

```sh
brew tap maxsiomindev/cliph
brew install --cask cliph
```

## Uninstall

```sh
brew uninstall --cask cliph
brew untap maxsiomindev/cliph
```

`--zap` removes preferences and history too:

```sh
brew uninstall --cask --zap cliph
```
